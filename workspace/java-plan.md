# برنامه یادگیری Java — سه هدف اصلی

## هدف ۱: تسلط بر مبانی و OOP
- یادگیری سینتکس، انواع داده، حلقه‌ها و شرط‌ها
- درک کامل شی‌گرایی: کلاس، شی، وراثت، پولیمورفیزم و کپسوله‌سازی
- تمرین روزانه با حل مسائل ساده در Java

## هدف ۲: کار با کتابخانه استاندارد و مدیریت پروژه
- آشنایی با Collections، Streams، مدیریت فایل و Exception Handling
- یادگیری Maven/Gradle و کار با Git
- ساخت پروژه‌های کنسولی کامل و تمیز

## هدف ۳: توسعه اپلیکیشن‌های تحت وب با Spring Boot
- یادگیری Spring Core و سپس Spring Boot
- ساخت REST API و اتصال به پایگاه داده (JPA/Hibernate)
- استقرار یک پروژه واقعی و افزودن آن به پورتفولیو
